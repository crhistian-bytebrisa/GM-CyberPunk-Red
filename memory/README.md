# Memoria de la partida

Fuente de verdad del estado de la partida. El GM debe consultarla antes de narrar y actualizarla tras escenas relevantes.

## Archivos
- `personaje.md` — ficha del personaje del jugador.
- `misiones.md` — misiones activas/completadas.
- `npcs.md` — NPCs conocidos.
- `lugares.md` — lugares visitados.
- `facciones.md` — facciones y reputación.
- `inventario.md` — equipo, armas, cyberware, dinero.
- `mundo.md` — estado del mundo (fecha, heat, eventos, rumores).
- `bitacora.md` — log cronológico de sesiones.

## Regla
Si no está en memoria, no ha pasado. Actualizar con skill `memory-update`.
