# Documentos de Cyberpunk Red

## Guías y reglas descargadas

### Guías oficiales (R. Talsorian Games)
- `cyberpunk-red-guia-basica.md` — Resumen de reglas básicas (stats, roles, combate, curación, cyberware, economía, netrunning, lifepath, movimiento, creación de personaje).
- `FAQ.pdf` — FAQ oficial de Cyberpunk RED (10 páginas).
- `JumpstartConversionGuide.pdf` — Guía de conversión de Jumpstart Kit a Core RED (NPCs, reglas).

### DLCs y ayudas de juego
- `CollectingTheRandom.pdf` — Posts de redes sociales sobre gameplay e ideas.

- `HardenedMooks.pdf` — Mooks más fuertes para enemigos.
