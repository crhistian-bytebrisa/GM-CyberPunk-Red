# CyberPunkRed

Sistema de juego de rol asistido por IA para **Cyberpunk Red** (R. Talsorian Games), integrado con OpenCode.

## Inicio rápido
1. Abre este proyecto en OpenCode.
2. Escribe `/jugar` para iniciar/continuar la partida.
3. Si no tienes personaje, usa `/crear-personaje`.

## Estructura
- `AGENTS.md` — instrucciones del Game Master.
- `skills/` — skills especializadas.
- `commands/` — comandos slash.
- `memory/` — estado persistente de la partida.
- `rules/` — reglas resumidas.
- `lore/` — lore del mundo.
- `templates/` — plantillas.

## Idioma
Español.
